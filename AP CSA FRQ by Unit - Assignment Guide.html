📍 UNITS 1-3: FRQ 1 - Methods & Control Structures
When to assign: After teaching Unit 3 (Boolean Expressions & if Statements)
What it tests: Method writing, primitive types (int, double, boolean), arithmetic, boolean logic, control flow
Practice progression: Start with 2018-2019 (foundational) → 2022-2023 (intermediate) → 2024-2026 (exam-level)

✅ Assignment Tips:
• Start with Unit 1-3: Use FRQ 1 questions (2018-2019) as foundational practice
• Increase difficulty: Assign 2022-2026 FRQ 1 as students become more proficient
• Follow the unit sequence: Don't assign FRQ 4 before Unit 8 is complete
• Mix old and new: Use older questions for practice, newest for final assessments
• Timing: Budget 18-22 minutes per FRQ in class; students need time to write code
